# 付费客户商业交付问询指南 (Client Inquiry & Consultation Guide)

在为付费客户或第三方用户提供 PC 极限减负服务时，专业、清晰、尊重用户习惯的沟通不仅能建立极高的信任度，更是防范误删事故的核心防线。

---

## 1. 探查交互四步法 (The 4-Step Discovery Flow)

当以商业交付模式 (`$win-purify --client`) 启动时，Agent 必须通过 `ask_question` 或清晰的多选题呈现以下问卷：

### 问题 1：常玩的游戏与关键娱乐资产
> “请问您这台电脑平时主要玩哪些大型游戏或电竞网游？”
- **选项 A (常用竞技)**：三角洲行动、瓦罗兰特 / 无畏契约、CS2、守望先锋、APEX、英雄联盟
- **选项 B (3A大作)**：黑神话：悟空、赛博朋克 2077、荒野大镖客2、使命召唤 (COD)
- **选项 C**：不玩大型游戏，主要是办公与日常娱乐
- **选项 D**：其他（用户自行补充）
> **决策依据**：
> - 若有《三角洲行动》或《COD》，追问是否需要剔除 4K 可选超清材质大包（说明：仅移除 4K 极限贴图，不影响排位、帧数与常规画质，直接回血 15~20 GB）。
> - 若有带内核反作弊的游戏，严格禁止使用可能导致蓝屏的内核注册表项。

### 问题 2：后台不可关闭的常驻与生产力工具
> “有哪些工具软件是您平时工作生活必须开机自启、随时在后台待命的？”
- **选项 A (远程与同步)**：向日葵 / ToDesk / 网易UU远控、坚果云 / 百度网盘 / 谷歌网盘 / OneDrive
- **选项 B (网络加速/代理)**：各类游戏加速器（网易UU/雷神/迅游）、网络代理/梯子工具
- **选项 C (企业通信)**：微信、企业微信、飞书、钉钉
- **选项 D**：没有特别依赖，除了安全软件其余自启都可以精简
> **决策依据**：客户勾选的所有应用自动加入永久白名单，严禁修改其自启动注册表项或杀其服务。

### 问题 3：开发工程与设计资产安全排查
> “您电脑上是否存在正在进行中的编程项目代码、设计工程或本地数据库？”
- **选项 A (专业开发者)**：有正在开发的项目（Node.js, Python, Java, Rust, Docker 等）
- **选项 B (非技术用户)**：完全没有代码或开发环境，纯个人或商务办公使用
> **决策依据**：
> - 选 A：向用户解释“代码无损脱水”逻辑（绝对保护源码与 Git，仅清理陈旧项目的 `node_modules` / `.venv` / 构建产物），询问指定的项目根目录路径。
> - 选 B：彻底跳过代码脱水模块。

### 问题 4：清理激进等级与偏好
> “您期望本次清理优化的激进程度是怎样的？”
- **选项 A (推荐 · 均衡安全级)**：全面释放系统空间与驱动仓库，清理冗余缓存，治理开机后台偷跑进程，不卸载原生自带应用。
- **选项 B (激进 · 极客纯净级)**：在均衡级基础上，额外卸载 Win11 原生无用预装软件（小组件、手机连接、Xbox全家桶），优化虚拟内存配额，追求极度干净。
- **选项 C (保守 · 基础释放级)**：仅清理垃圾文件与浏览器缓存，锁定崩溃转储，不动自启项与驱动。

## 2. 交付成果标准报告模板 (Delivery Template)

交付完毕后，必须生成如下格式的标准报告输出给客户：

```markdown
# 🚀 PC 深度净化与系统加速交付报告

- 📅 **交付时间**：[YYYY-MM-DD HH:mm]
- 💻 **操作系统**：Windows [10/11]
- 🛡️ **安全状态**：通过零破坏性校验，业务数据与游戏环境 100% 完好

---

### 一、核心优化战果
| 维度 | 优化前 | 优化后 | 收益提升 |
| :--- | :--- | :--- | :--- |
| **C 盘可用空间** | [XX] GB | [XX] GB | **大幅释放 +[XX] GB** |
| **开机闲置内存** | [XX] GB ([XX]%) | [XX] GB ([XX]%) | **压制节省约 [XX] GB** |
| **驱动仓库冗余包** | [X] 个 | 0 个 (仅留活动驱动) | **清理 [X] GB 废弃驱动** |
| **开机后台幽灵进程** | [XX] 个 | [XX] 个 | **封堵 [X] 个偷跑程序** |

---

### 二、客户专属资产保护说明
- 🎮 **游戏与反作弊**：已对 [客户游戏列表] 做了反作弊驱动隔离，核心配置完好。
- 💼 **办公与远程工具**：已严格保留 [客户指定的白名单] 开机常驻与自启动。
- 📂 **工程与文档安全**：所有代码、文档与个人文件夹 100% 原样保留。

---

### 三、建议操作
建议您现在重启一次电脑。重启后：
1. Windows 会彻底完成驱动仓库与组件存储的物理回收。
2. 虚拟内存配额生效，C 盘空间将达到峰值可用状态。
```
